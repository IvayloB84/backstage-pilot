======================================================================
         ARGOCD GITOPS ENGINE STATUS VERIFICATION COMMANDS
======================================================================

--- 1. CHECK THE GLOBAL AUTO-SYNC, PRUNE, AND SELF-HEAL STATES ---
Command:
  kubectl get application backstage-pilot-gitops -n argocd -o jsonpath='{.spec.syncPolicy.automated}'
Information:
  Verifies your automated tracking policies. Based on your rules, 
  it must output {"prune":false,"selfHeal":false} to ensure manual 
  hot-patches are safe from being overwritten.

--- 2. PRINT TARGET TRACKING PATHS AND REPOSITORY SOURCE INFO ---
Command:
  kubectl get application backstage-pilot-gitops -n argocd -o jsonpath='{"Repo: "}{.spec.source.repoURL}{"\n"}"Path: "}{.spec.source.path}{"\n"}'
Information:
  Displays the exact GitHub repository URL and folder tree path 
  ArgoCD is watching for new infrastructure items.

--- 3. VERIFY HEALTH STATUS AND SYNC CONDITIONS ---
Command:
  kubectl get application backstage-pilot-gitops -n argocd -o jsonpath='{"Status: "}{.status.sync.status}{"\n"}"Health: "}{.status.health.status}{"\n"}'
Information:
  Returns the direct connection health. Look for "Synced" or "OutOfSync" 
  (which is normal now since we allowed manual drift) and "Healthy".

--- 4. LIST ALL INDIVIDUAL TRACKED CLUSTER RESOURCES ---
Command:
  kubectl get application backstage-pilot-gitops -n argocd -o jsonpath='{range .status.resources[*]}{.kind}{"\t"}{.name}{"\t"}{.health.status}{"\n"}{end}'
Information:
  Prints a clean list of every deployment, service, and configmap 
  ArgoCD is actively supervising inside the cluster.

--- 5. CHECK THE LAST COMPICKED REVISION AND SYNC TIME ---
Command:
  kubectl get application backstage-pilot-gitops -n argocd -o jsonpath='{"Revision: "}{.status.sync.revision}{"\n"}"Finished: "}{.status.sync.finishedAt}{"\n"}'
Information:
  Confirms the exact Git commit hash ArgoCD last processed, allowing 
  you to check if it has picked up your newest additions.
